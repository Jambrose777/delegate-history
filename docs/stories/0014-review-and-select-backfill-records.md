# 14. Review and select backfill records

**Status:** Needs Refinement

#### Acceptance criteria

- Authorized users can filter local history and select individual entries, all entries, or all entries matching the current filter.
- The review view distinguishes missing, approximate, suggested, approved, and already-present-in-WCA entries.
- Approximate ranges, missing dates, and unresolved conflicts are not migration-ready.
- Selection state is clear before migration generation.
