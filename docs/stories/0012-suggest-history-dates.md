# 12. Suggest history dates

**Status:** Needs Refinement

#### Acceptance criteria

- Invited suggestors can propose a date for a WCA-linked person/history item.
- Each suggestion requires a comment explaining its evidence, for example which email supports the date.
- Suggestions preserve the proposed date, approximate marker, source, and comment for approver review.
- A suggestion is not itself an approved date fact; an approver must promote it into a date fact.
